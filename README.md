## Executive Summary

I build practical, production-oriented **Computer Vision** and **OCR** systems—covering data preparation, model training, evaluation, and deployable inference pipelines. My work focuses on real-world performance, clean engineering, and reproducible experiments. This profile highlights open-source projects around **Arabic OCR**, **neural networks from scratch**, and applied DL/CV systems.
